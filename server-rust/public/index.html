스플릿 터널 정책

구체 도메인(crm.example.com)은 서버가 주기적으로 IP를 재해석해 접속 시 라우트로 내려주고, 와일드카드(*.example.com)는 클라이언트가 DNS 응답을 스니핑해 실시간으로 라우팅합니다. CDN 도메인은 두 형태를 함께 넣는 것이 가장 안정적입니다.

저장하면 즉시 재해석되어 데이터베이스에 기록되며, 재시작해도 유지됩니다. 이후에 연결하는 클라이언트부터 적용되므로 기존 연결은 재연결이 필요합니다.

서버 설정

여기서 바꾼 값은 데이터베이스에 저장되어 재시작해도 유지됩니다. 접속 정보와 인증 비밀키는 안전을 위해 환경변수로만 관리합니다.
